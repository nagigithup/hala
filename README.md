# Hala

Hala is a responsive bilingual portal for day-to-day ERPNext work. It uses the
standard ERPNext documents, permissions, controllers, workflows, stock ledger,
and general ledger. It does not define replacement business documents.

After installation, open `/hala`. Users need the **Hala Portal User** role plus
the normal ERPNext roles and user permissions required for the records they use.
System Managers can always open the portal.
